# PocketPlan — 제품 요구사항 정의서 (PRD)

> 개인 월급 기반 → 지출 입력 → 저축 가능 금액 자동 계산 → 월별 기록 관리.
> "스프레드시트로 하던 가계부"를 웹앱으로 구조화한다.

최종 수정: 2026-06-04

---

## 1. 핵심 컨셉
한 줄 요약:
> 월급 자동 이월 → 수입 입력 → 지출 관리(고정/변동/할부) → 총 지출 계산 → 저축액 표시 → 다음 달 이동 → 과거 기록 확인

## 2. 사용자 흐름 (UX Flow)

### 2.1 월의 시작 — 기본 월급 자동 불러오기
- 신규 달 진입 시 이전 달 월급을 자동 이월한다.
- "월급 변경" 버튼으로 수정 가능.
- **수용기준**: 새 달의 월급 = 직전 달 월급(없으면 0/입력 요청).

### 2.2 해당 월의 수입 등록
- 수입 유형: 월급(기본 자동) / 보너스·성과급 / 추가 수입(중고거래, 용돈 등). 여러 건 가능.
- **이번 달 총 수입 = 모든 수입 합계.**

### 2.3 고정 지출 입력
- 매달 반복: 월세, 관리비, 보험료, 통신비, 정기구독 등.
- 한 번 설정하면 매달 자동 복사. 수정/삭제 가능.

### 2.4 변동 지출 입력
- 매달 달라짐: 식비, 교통, 쇼핑, 병원비, 취미 등.
- 1회성 입력 위주. 새 달에는 비워진다.

### 2.5 할부 지출 처리
- 입력: 전체 개월수(예: 5) / 이번 달 회차(예: 2/5) / 금액.
- 다음 달 자동으로 회차 증가(3/5, 4/5 …). 마지막 회차 후 종료(복사 중단).

### 2.6 총 지출 자동 계산
```
총 지출 = 고정 지출 합계 + 변동 지출 합계 + 이번 달 할부 지출 합계
```

### 2.7 저축 가능 금액 표시
```
저축 가능 금액 = 총 수입 − 총 지출
```
- 대시보드에서 강조 표시. 음수면 경고 표시.

### 2.8 다음 달로 전환
| 항목 | 동작 |
|---|---|
| 기본 월급 | 자동 이월 |
| 수입(보너스/추가) | 초기화 |
| 고정 지출 | 자동 복사 |
| 할부 지출 | 자동 복사 + 회차 +1 (완료분 제외) |
| 변동 지출 | 비워짐 |

### 2.9 History 페이지
- 연도/월별 카드로 요약: 총 수입, 총 지출, 저축액.
- 상세 페이지 연결(확장).

## 3. 데이터 모델 (초안 — Prisma)
> 개발/기획 에이전트가 확정. 현재 `schema.prisma`에 모델 미정의 상태.

- **User**: id, email, … (인증)
- **Month**: id, userId, year, month, salary(이월 대상), createdAt — (userId, year, month) 유니크
- **Income**: id, monthId, type(salary|bonus|etc), label, amount
- **Expense**: id, monthId, kind(static|variable|installment), label, amount
- **Installment**: id, label, totalMonths, currentRound, amount, sourceRef(원 할부 추적), monthId

> 결정 사항은 `DECISIONS.md`, 진행은 `PROGRESS.md` 참고.

## 4. 비기능 요구사항
- 금액은 정수(원). 부동소수점 금지.
- 금융 데이터는 사용자별 격리(보안 필수).
- 핵심 계산 로직은 순수 함수로 분리(테스트 용이).

## 5. 범위 (MVP 경계선)
- **MVP (이번 목표 — "첫 화면에 저축액이 뜬다")**: 단일 사용자(인증 없음, 고정 userId) · 캘린더 월(단일 월) · 수입/지출(고정·변동·할부) 입력+저장 · 총수입/총지출/저축액 계산 · 요약 대시보드(저축액 강조).
  - MVP 최소 선행조건: 데이터 모델 확정 → 계산 순수 함수 → 저장(Server Action) → entry/overview UI.
- **확장 (MVP 이후)**: 월 자동 전환/이월(월급·고정 복사, 변동 비움, 수입 초기화), 할부 회차 자동 +1/종료, History 페이지, 인증(NextAuth), 다중 사용자/데이터 격리, 그래프/상세.
